# Palette

Based on Alacritty's default dark colors. Every port uses these values; change them here first.

| Role | Hex |
|---|---|
| background | `#181818` |
| raised surface (active tab, panels) | `#282828` |
| selection | `#383838` |
| foreground | `#d8d8d8` |
| bright foreground | `#f8f8f8` |
| muted (comments, inactive) | `#7f7f7f` |

| ANSI | Normal | Bright |
|---|---|---|
| black | `#181818` | `#6b6b6b` |
| red | `#ac4242` | `#c55555` |
| green | `#90a959` | `#aac474` |
| yellow | `#f4bf75` | `#feca88` |
| blue | `#6a9fb5` | `#82b8c8` |
| magenta | `#aa759f` | `#c28cb8` |
| cyan | `#75b5aa` | `#93d3c3` |
| white | `#d8d8d8` | `#f8f8f8` |

Syntax red is brightened to `#d06060` in editor-style ports for contrast (4.7:1 on the background).
Font: `IosevkaTerm Nerd Font Mono`.
